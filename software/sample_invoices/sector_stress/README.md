# Massas sintéticas por setor

Cada ZIP contém 300 NF-e sintéticas, cinco por mês, entre setembro de 2021 e
agosto de 2026. Os arquivos internos estão separados em:

- `monofasicos_cst_04`: produto monofásico com CST coerente;
- `monofasicos_cst_comum`: produto monofásico com CST comum, útil como sinal de revisão;
- `nao_monofasicos`: produto fora do catálogo monofásico operacional do Audita.

Arquivos:

- `autopecas_300_xmls_60_meses.zip`;
- `farmacia_300_xmls_60_meses.zip`;
- `bar_300_xmls_60_meses.zip`.

Todos os dados são fictícios e estão marcados como `SEM VALOR FISCAL`.
O termo técnico usado pelo Audita é regime monofásico/alíquota zero na revenda,
não uma isenção tributária genérica.
